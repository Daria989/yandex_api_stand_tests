# Яндекс.Прилавок
Учебное веб-приложение имитирующее функциональность маркетплейса и сервиса по доставке еды

### В репозитории описаны тесты на проверку параметра firstName при создании пользователя с помощью API.
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest
